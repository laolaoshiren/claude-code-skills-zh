# AI 视频制作流水线（中文优先）

## 触发条件

当用户出现以下意图时启用：

- 「帮我把这个话题做成视频」「写个脚本，我要拍/生成一条视频」
- 「这条口播稿帮我改成分镜」「把文章改成视频」
- 「做一条 60 秒的抖音 / B 站 / 小红书视频」
- 「我有一堆素材，剪成一条片子」
- 「这个视频的风格不错，用同样的风格做一集」

不适用：纯剪辑软件操作教学、纯字幕翻译、单张图片生成。

## 核心原则

1. **先定提案再动素材。** 视频的成本几乎都在「生成/拍摄」阶段，脚本没定就开跑，最后大概率整条重做。
2. **反盲盒抽卡。** 不要靠「多生成几版挑一条」，而是把可控变量（分镜、首尾帧、时长、镜头运动）先锁定，再逐段生成、逐段验收。
3. **中文节奏优先。** 中文字幕、中文配音、中文断句的规则和英文完全不同，不能直接套用英文模板。
4. **每阶段有门禁。** 上一阶段没通过验收标准，不进入下一阶段。

## 第一步：先判断档位

不要一上来就问一堆参数。先按用户手上有什么，判断档位：

| 档位 | 用户特征 | 你的做法 |
|------|---------|---------|
| **A. 零基础** | 「我就想做个视频」 | 只问 3 件事：讲什么、多长、发哪个平台。其余由你给默认值并说明理由 |
| **B. 有素材** | 已有一堆图/视频/录音 | 先做素材盘点与分类，再倒推能讲什么故事 |
| **C. 专业** | 给了分镜表、风格参考、时间线 | 按对方的表格走，你补全缺失字段并做技术校验 |

**必问三件事（A 档只需这三项）：**

1. **主题**：一句话说清「给谁看、看完记住什么」。
2. **时长与平台**：抖音/视频号 15–60 秒（9:16）、B 站 3–10 分钟（16:9）、小红书 30–90 秒（3:4 或 9:16）。
3. **预算上限**：是否使用付费模型/TTS/素材库；没有预算就走本地或免费方案。

## 第二步：八阶段流水线

每个阶段都产出**可检查的中间产物**，而不是直接跳到成片。

### 阶段 1｜调研（Research）

产出：`research_brief`

- 至少做 5 次检索，覆盖：主题事实、同类视频的常见结构、可用素材来源、版权限制、目标平台的规则。
- 记录**具体来源 URL**，不要写「据研究」。
- 明确写出「哪些说法没有可靠来源」——这些内容要么删掉，要么在成片里避免下断言。

**门禁**：调研简报里的每个关键结论都能指到具体来源；找不到来源的结论已标注。

### 阶段 2｜提案（Proposal）

产出：`proposal_packet` + `decision_log`

给 **2–3 个方向**，每个方向写清：

- 一句话立意（这条片子想让观众记住什么）
- 结构（开头 3 秒钩子 → 中段推进 → 结尾落点）
- 视觉风格（实拍 / 生成 / 图文动画 / 混合）
- **成本估算**（调用次数、付费 API、素材授权）
- 风险（哪里可能做不出来）

**门禁**：用户明确选定一个方向后才继续。**不要替用户默认选择后再回头问。**

### 阶段 3｜脚本（Script）

产出：`script`

中文口播稿的硬规则：

- **语速**：中文口播约 **每秒 4–5 字**。60 秒 ≈ 240–300 字，超了就要砍。
- **断句**：一句话不超过 **25 字**，长句拆成短句，便于配音和字幕。
- **开头 3 秒**：第一句必须是钩子（冲突、反常识、具体数字），不要「大家好，今天我们来聊聊」。
- **口语化**：写完朗读一遍，拗口的地方就是字幕会断得难看的地方。
- **数字与专名**：阿拉伯数字与英文专名单独标注读法，避免 TTS 读错。

**门禁**：整稿朗读时长与目标时长误差 ≤ 10%。

### 阶段 4｜分镜（Storyboard）

产出：`storyboard`（表格）

| 镜号 | 时长 | 画面描述 | 景别/运镜 | 口播/字幕 | 素材来源 | 备注 |
|------|------|---------|----------|----------|---------|------|

要点：

- **每个镜头 ≤ 8 秒**。超过就拆，长镜头是 AI 生成最容易崩的地方。
- **首尾帧先行**：生成类镜头先把首帧和尾帧定下来，再让模型补中间，能大幅降低「人物转头穿帮」。
- **跨段一致性**：同一角色的镜头，提前准备统一的定妆描述（发型、服装、光线），每段都带上。
- **标注可替代方案**：某镜头如果生成失败，用什么素材顶上。

**门禁**：分镜总时长 = 脚本总时长；每个镜头都有素材来源；没有「待定」的镜头。

### 阶段 5｜素材（Assets）

产出：`asset_manifest`

按来源分三类处理：

- **生成素材**：先出低分辨率/低步数预览确认构图，确认后再出成品。**不要一上来就出高清全片。**
- **采集素材**：记录来源、许可、作者；商用前逐一核对授权。
- **自制素材**：图表、字幕条、片头片尾，优先用可复现的模板生成，避免每次手调。

**门禁**：每个素材都有来源与许可记录；成品素材的分辨率、帧率、色彩空间与时间线一致。

### 阶段 6｜剪辑（Edit）

产出：`timeline`

- 先粗剪（按分镜顺序拼接），再精剪（节奏、转场、留白）。
- **中文视频的节奏**：信息密度高的段落每 3–5 秒要有一个视觉变化，否则观众会划走。
- **转场克制**：默认硬切；花式转场只在段落切换时用一次。
- **留气口**：口播之间留 0.2–0.3 秒静音，观众才听得清。

**门禁**：粗剪版本连续看一遍不打瞌睡；没有明显黑帧、跳帧、音画不同步。

### 阶段 7｜合成（Compose）

产出：`compose_report`

- **配音**：中文 TTS 优先选自然度高的音色；同一角色全片用同一个 voice id，**绝不中途更换**（否则跨段变声）。
- **去播音腔**：给 TTS 加标点停顿、轻微语速变化；能本地克隆音色时优先用真人样本。
- **字幕**：
  - 每行 **≤ 14 个汉字**，最多 2 行；
  - 按语义断句，不要按字数机械切分；
  - 数字用阿拉伯数字，专名保留原文；
  - 逐字对齐（卡拉 OK 式）时，字幕提前音频 0.05–0.1 秒出现。
- **音乐与音效**：人声 -6dB 左右，音乐再低 12–18dB；不要用有版权风险的商用曲。
- **混音检查**：手机外放听一遍，这是大多数观众的收听环境。

**门禁**：字幕无错别字、无溢出、无遮挡人脸；人声清晰可辨；无爆音。

### 阶段 8｜导出（Publish）

产出：`deliverables`

按平台导出：

| 平台 | 比例 | 分辨率 | 备注 |
|------|------|--------|------|
| 抖音 / 视频号 / TikTok | 9:16 | 1080×1920 | 前 3 秒最关键 |
| B 站 / YouTube | 16:9 | 1920×1080 | 可 4K，时长容忍度高 |
| 小红书 | 3:4 或 9:16 | 1080×1440 / 1080×1920 | 封面单独做 |
| 视频号 | 9:16 | 1080×1920 | 封面字要大 |

同时交付：

- 封面图（按平台单独出，不要从视频里截一张了事）
- 标题与简介（中文，不超过平台限制）
- 字幕文件（`.srt` 或 `.ass`）
- 素材清单与授权记录

**门禁**：每个平台的文件都能正常播放；封面在手机小屏上能看清主标题。

## 第三步：常见坑与处理

| 现象 | 原因 | 处理 |
|------|------|------|
| 跨段人物变声 | 每段用了不同 TTS 音色 | 全片锁定同一 voice id，重新生成异常段 |
| 后段画面发雾发灰 | 多段续接时潜空间漂移 | 用上一段尾帧作为下一段首帧，或降低续接段数 |
| 人物向镜头错误转头 | 首尾帧未锁定 | 用首尾帧夹具固定构图，镜头运动写进描述 |
| 口型对不上 | 先出画面后配音 | 先定配音，再按音频时长生成画面 |
| 字幕挡住人脸 | 未做安全区检查 | 字幕放在底部 15% 安全区内，避开主体 |
| 生成 20 版挑不出 | 盲盒式抽卡 | 回到阶段 4 锁分镜与首尾帧，问题不在「版数」 |
| 单段要改却重跑全片 | 没有分段渲染 | 按镜号分段输出，改哪段只重跑哪段 |

## 第四步：成本控制

- **先定预算上限**，写进提案，超过就停下来问用户。
- **分阶段付费**：调研与脚本阶段几乎零成本，不要把预算烧在还没定稿的素材上。
- **预览优先**：生成类素材先出低清预览，确认后再出成品。
- **复用**：片头、片尾、字幕条、转场模板做成可复用组件，第二条视频起成本会大幅下降。
- **记录每次调用的实际消耗**，交付时给用户一份成本账。

## 输出格式

每次交付给用户时，按这个结构：

```markdown
## 视频方案

**主题**：
**平台与时长**：
**档位**：A 零基础 / B 有素材 / C 专业

### 1. 调研要点（含来源）
### 2. 选定方向与理由
### 3. 脚本（含预计时长）
### 4. 分镜表
### 5. 素材清单与授权
### 6. 剪辑与字幕说明
### 7. 导出文件清单
### 8. 成本账与风险说明
```

## 注意事项

- **版权**：生成素材同样可能有版权与平台规则限制；使用他人视频做「风格参考」时，不要复制其画面、旁白、logo 与主播形象。
- **肖像与声音**：克隆他人声音或形象必须取得授权；不确定时改用中性配音与原创画面。
- **事实核查**：视频一旦发布传播成本很高，脚本阶段的每个数字与结论都要有来源。
- **平台规则**：医疗、金融、教育等敏感领域的内容，发布前提示用户自行核对平台与监管要求。
- **不承诺效果**：不写「 guaranteed 上热门」「保证涨粉」这类话。
