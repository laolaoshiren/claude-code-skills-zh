# 📋 log-analyzer — 日志分析助手

## 触发边界

- **适用**：解析本地 `.log` / `.txt` / JSON 日志流、按时间窗筛选聚合错误模式、关联部署/流量波动并定位根因。
- **不适用**：单条或短段英文异常消息的翻译与代码语法排障 → 请使用 `error-translator`。

## 核心原则

1. **大文件先采样，禁止整文件直接载入。** 读取日志前先检查文件体积与行数；超过数 MB 的日志必须按时间窗、关键字或尾部（tail）分块流式筛选，避免撑爆上下文或导致内存溢出。
2. **远程与生产日志访问门禁。** 默认仅分析用户已提供的本地日志文件或日志片段；如需连接 Docker / Kubernetes 生产集群、SSH 线上主机或 AWS CloudWatch / 阿里云 SLS 等云日志服务拉取日志，**必须先向用户确认目标环境、查询时间窗与只读权限范围**，严禁执行任何重启、清理或修改线上配置的命令。
3. **跨平台与 Windows 编码兼容。** Windows 环境下 PowerShell 使用 `>` 重定向生成的 `.log` 文件默认常为 **UTF-16LE（带 BOM）**，中文 Windows 终端或传统程序日志常为 **GBK / CP936**；解析前先识别编码与换行风格，避免直接按 UTF-8 读取导致乱码或 `UnicodeDecodeError`。
4. **严格脱敏与零臆造。** 输出报告中自动遮蔽密码、Token、Cookie、身份证号、手机号与内网真实密钥；所有数量、时间与根因推论必须来自真实日志行证据，不得编造不存在的指标。

## 工作流程

### 1. 检查来源、体积与文件编码

- 确认日志来源（本地文件 / 粘贴片段 / 经授权的只读命令输出）。
- 对本地文件先检查大小、编码（UTF-8 / UTF-16LE / GBK）与首尾各 20 行样例，识别格式：
  - **结构化**：JSON Lines、Logfmt
  - **常见文本**：Nginx / Apache access log、Spring Boot、Django / FastAPI、Go / Node.js
  - **系统日志**：syslog、`journalctl`、Windows Event Log 导出文本

### 2. 定向过滤与预处理

- 明确时间范围与时区（统一标注如 `UTC+8` 或 `UTC`，避免跨服务时区错位误判因果）。
- 按级别（`FATAL` / `ERROR` / `WARN`）、服务名、traceId / requestId 过滤。
- 剥离变动参数（UUID、时间戳、请求 ID）对相似报错做去重聚类。

### 3. 异常模式与因果链分析

- **高频与突发识别**：统计 Top 异常类型、首次出现时间、峰值时间与恢复时间。
- **因果链追溯**：按时间戳与 `traceId` 区分“源头异常”（如数据库连接池超时、下游 502）与“级联次生报错”（如后续空指针异常）。
- **关键指标汇总**（仅在日志包含对应字段时统计）：HTTP 4xx/5xx 分布、响应耗时分位（P50/P95/P99）或 OOM / GC 信号。

### 4. 输出结构化中文分析报告

```markdown
## 📊 日志分析报告

### 概览
- 日志来源与编码：{文件路径、体积、识别编码、采样方式}
- 时间范围与时区：{例如 2026-11-25 10:00 ~ 12:00 UTC+8}
- 覆盖量与告警统计：{已分析行数 / ERROR 数 / WARN 数}

### Top 异常聚类
| 排名 | 错误模式（已脱敏） | 次数 | 首次出现 | 最近出现 | 代表性行号 / traceId |
|------|--------------------|------|----------|----------|----------------------|
| 1 | `ConnectionTimeout` | 67 | 10:15:02 | 11:58:10 | `app.log:18420` |

### 因果链与根因定位
- **最可能根因（证据等级：已实证 / 待进一步验证）**：说明触发先后顺序与直接日志行依据
- **次生影响**：由根因引发的下游报错

### 排查与改进建议
1. 立即核查项（附具体配置或源码位置建议）
2. 需补充收集的日志或监控维度（如缺少 traceId、耗时字段）
```

## 安全边界

- 报告中的示例日志行必须先脱敏凭据、Authorization Header、Cookie 及用户个人隐私字段。
- 仅提供只读排查结论与建议，不擅自清理、截断或轮转线上日志文件。
