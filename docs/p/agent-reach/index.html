📦 Agent 一句话安装与统一目录管理

Agent-Reach 把所有渠道工具、专用浏览器会话和配置统一收敛在 ~/.agent-reach/ 目录下（不污染系统 Python 与全局环境）。安装、升级和卸载都可以直接用自然语言交给 Claude Code / Codex / OpenClaw 完成：

方式 A：发给 Agent 自动安装（官方首选）

Windows / macOS / Linux

允许 Agent 执行命令后发送以下指令；若系统未装 uv，Agent 会自动免管理员安装并初始化 5 个默认渠道。

发给 Claude Code / Codex 的指令 
帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/Agent-Reach/main/docs/install.md

方式 B：常用 CLI 查询与口语化管理

全平台统一口令

装好后 Agent 可按 URL 自动识别渠道，或随时增减可选渠道与检查健康度。

CLI 与日常管理 
# 查看各渠道可用状态与健康检查
agent-reach channels

# 搜索 B 站或按链接自动识别平台读取
agent-reach bilibili search "大模型"
agent-reach read https://www.v2ex.com/t/123

# 配置语音转文字 Key（务必在本地终端输入，勿发给聊天框）
agent-reach configure groq-key

🔌 核心设计理念：首选 + 备选的有序降级链路

社交平台改版、反爬升级和上游脚本失效是常态。Agent-Reach 不让 Agent 直接硬编码某个脆弱爬虫，而是把每个渠道拆成「统一口令层 → 策略路由层 → 多工具备选池」：

1. 稳定调用契约

Agent 始终只需记住 agent-reach <渠道> <动作> 或 agent-reach read <URL>，并配有自带技能说明 agent_reach/skill/。

2. 自动失败回退

如 B 站先走 bili-cli 失败再回退公开接口；网页正文先走 Jina Reader 再切 Exa，单点失效不影响整体交付。

3. 一键体检与换账号

对 Agent 说「看看 Agent Reach 状态」「小红书登录过期了」或「卸载 Agent Reach」，即可精准定位坏掉的渠道或清理单一站点登录态。

🛡️ 安全红线、假包避坑与合法使用边界

🚫 警惕 PyPI 同名假包与虚假加密代币
  • 严禁从 PyPI 安装 agent-reach：官方明确声明 PyPI 上的同名包并非本项目，务必只使用 GitHub 仓库与 docs/install.md 安装。
  • 防诈骗声明：项目没有任何官方代币、空投或钱包连接活动，切勿连接任何借用 Agent-Reach 名义的加密站点。
⚠️ 账号风控、Key 保密与合规采集边界
  • 专用浏览器隔离 + 建议用小号：需要登录的平台只在后台启动本机可连的专用浏览器，初次会复制 Chrome 对应站点的 Cookie（不触碰密码库）；因平台可能对自动化访问限流，强烈建议切为小号。
  • Key 勿入聊天上下文：YouTube / 小宇宙转文字所需的 Groq 或 OpenAI Key，请直接在终端运行 agent-reach configure groq-key 写入，不要直接粘贴到 AI 对话框。
  • 只读不写与平台合规：工具定位为辅助调研与个人阅读，请遵守目标平台服务条款与频率控制，勿用于大规模商业爬取。

❓ 常见问题 FAQ

Q1：国内网络环境下访问 GitHub raw 地址安装困难怎么办？

官方 README 底部提供了 AtomGit 同步镜像（atomgit.com/qq_51337814/Agent-Reach），国内拉取代码或参考安装文档更稳定，但仍需注意核对上游原仓说明，避免使用来源不明的 PyPI 包。

Q2：它和 xpzouying/xiaohongshu-mcp 有什么区别，该怎么选？

如果你只需要把小红书图文搜索/读取/发笔记作为独立 MCP 接入，xiaohongshu-mcp 专注度更高；如果你希望用一个统一 CLI 同时覆盖 B 站、V2EX、雪球、GitHub、YouTube、X、小红书 等多平台调研并坚持严格只读，首选 Agent-Reach。

Q3：为什么装完默认只有 5 个渠道，小红书和雪球要单独加？

为了降低首次安装体积与账号风险，默认只启用免登录的 5 个通用渠道（bilibili、v2ex、github、youtube、web）。需要某平台时再对 Agent 说「帮我加上小红书」，才会按需安装该渠道依赖。

Q4：小宇宙播客和 YouTube 无字幕视频怎么转文字？

项目内置 transcribe.py 转录链路，当视频没有现成字幕或处理小宇宙播客音频时，需在本地终端通过 agent-reach configure groq-key 配置 Groq（或 OpenAI）密钥即可启用语音转文字。
