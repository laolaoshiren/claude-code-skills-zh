❓ 常见问题 FAQ

Q1：小改一行文案也要走 brainstorming + worktree 吗？会不会太慢？

Superpowers 专为「从零做功能、复杂重构和跨多文件改动」设计。日常修一个拼写或改几行 CSS 时，过于沉重的工作流反而会多消耗 Token；可以仅在主力开发仓开启，或明确指示跳过规划直接修复单点 bug。

Q2：为什么社区贡献者不能随便往 obra/superpowers 提新技能 PR？

原仓明确说明一般不接受新增独立 Skill 的 PR，因为每个技能都必须跨 15+ 种编码 Agent 兼容维护，且需要通过 superpowers-evals 行为评测。如果你想分享自己写的中文专项技能，更适合放到本仓库或独立 Skill 仓库。

Q3：用 Qwen Code / Kimi Code / Trae 等国内工具能完整享受这套流程吗？

Qwen Code 可直接通过 qwen extensions install obra/superpowers 从 Claude 市场格式安装；Kimi Code 在插件市场搜索 Superpowers 或运行 /plugins install https://github.com/obra/superpowers 即可接入。

Q4：我想给现有项目先补单元测试或做中文 Diff 审查，有更轻量的替代吗？

如果你暂时不想引入整套强制流程，可以直接单装本仓 MIT 原创技能 test-generator（测试生成）和 zh-code-reviewer（中文 git diff 审查），按需唤起、零上下文侵入。
