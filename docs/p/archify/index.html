🧩 源码核验：archify / archify-pr / viewer 三大能力

核验原仓根目录与 SKILL.md，Archify 并非简单的 Mermaid 封装，而是由核心技能、可选 PR 同伴技能和独立交互查看器三部分构成：

1. archify/ 核心技能

支持 10 种校验型图表（Architecture、Workflow、Sequence、Data Flow、Lifecycle、ERD、Class、Tree、Timeline、Waterfall），输出独立离线 HTML；同时内置架构诊断（Code Analysis），可把依赖关系画成环形星图和可旋转 3D 模型并定位循环依赖与复杂度热点（需用户同意后才运行）。

2. archify-pr/ 可选 PR 同伴

需从仓库源码按需加装。基于 git merge-base 三点范围把分支 diff、GitHub PR 或 GitLab MR 转为结构化变更导览图。对文档、锁文件、格式化等小改动保持静默，只报告代码证据，不臆断合并风险结论。

3. viewer/ 独立交互查看器

产出物为自包含本地 HTML（存放在 .archify/<type>-<slug>-<时间>/）：浏览器直接打开即可缩放平移、一键切深浅主题、点击节点追溯源码、高亮上游/下游路径，并导出 PNG、SVG、WebM 与 1200×630 路径分享卡片。

10 种内置图表速查（按任务选型）

图表类型 最适合的工程场景 写 Prompt 时建议交代的信息
Architecture / Data Flow 微服务拓扑、系统边界、数据管线与血缘追踪 范围、8–12 个核心组件、主链路与外部信任边界
Workflow / Lifecycle CI/CD、审批流、Agent 工具编排、订单状态机 参与者、正常分支、异常与重试/取消终态
Sequence / Waterfall API 鉴权、缓存回源、异步回调与单次请求耗时分布 调用方、被调用方、时序顺序、Span 耗时（注明实测或示意）
ERD / Class / Tree 数据库表结构、核心类继承关系、仓库目录能力拆解 表/字段/主外键基数，或根节点与各模块职责
Timeline 线上故障复盘、版本演进与里程碑回溯 带时区的时间点、关键事件与来源泳道

🎯 中文开发者三大高频落地场景

🏚️ 1. 接手大型遗留项目

老系统文档早已过时时，先让 Archify 扫描仓库输出 8–12 个核心组件的高层运行时图，再开启 Code Analysis 找出循环依赖与高耦合热点，点选问题节点就能直达对应源码。

📐 2. 写架构评审方案与技术分享

无需先写代码，用一句话描述方案就能出可交互评审页。评审会现场直接切深浅色、追踪请求路径；需要贴进飞书文档、语雀或 PPT 时，一键导出 PNG 或 Route Share Card。

🔍 3. PR / MR 重构变更可视化

搭配 archify-pr 或 archify.mjs compare 生成 Before / Delta / After 架构对比，让 Reviewer 直观看到本次重构改动了哪些模块边界，不再只盯着几千行 diff 盲审。

📦 安装与触发步骤（Windows / macOS / Linux 通用）

支持 Claude Code、Cursor、Codex CLI、OpenCode 与 GitHub Copilot。命令中的 --copy 直接复制文件而非建符号链接，对 Windows 普通终端尤为友好。

方式 1：一条 CLI 非交互安装（推荐）

Windows / macOS / Linux

把 --agent 设为你的主力工具（支持 claude-code、cursor、codex、opencode、github-copilot，可重复传多个）。

安装 archify 核心技能到 Claude Code 
npx -y skills@latest add https://archify.si --skill archify --agent claude-code --global --copy --yes

方式 2：直接让 AI Agent 读取 llms.txt 安装

免手敲参数

把官方 README_ZH.md 提供的这句指令原样发给当前 Agent，由其按你的客户端路径自动完成安装。

发送给 Agent 的安装口令 
Install Archify for me by reading https://raw.githubusercontent.com/tt-a1i/archify/main/llms.txt

可选扩展：按需加装 archify-pr 同伴技能

PR / MR 变更可视化

需先装好核心 archify，再从 GitHub 源码单独加装 archify-pr（不强制装，按团队 Code Review 需要选择）。

加装 archify-pr（以 Claude Code 为例） 
npx -y skills@latest add tt-a1i/archify --skill archify-pr --agent claude-code --global --copy --yes

安装后直接复用

直接发给 Agent 的中文提示词

⚙️ 中文用户实测注意事项与隐私控制开关

🔒 内网 / 零外联环境：关闭低频更新检查

官方说明安装后的 archify 含有一个约 24 小时一次、失败静默的稳定版提醒检查（仅访问 https://archify.si/skill-updates/archify/stable.json，绝不上传项目代码、本地版本、用户输入或设备标识，也不会自动下载更新）。如在公司内网或严格零外联环境使用，直接设置以下环境变量即可彻底关闭：

关闭更新检查环境变量（Windows PowerShell / Shell） 
# Windows PowerShell
$env:ARCHIFY_UPDATE_CHECK_DISABLED = '1'

# macOS / Linux
export ARCHIFY_UPDATE_CHECK_DISABLED=1
🎛️ 避免过度主动触发：按需控制 Explainer 与 PR 提醒
  • 控制一页式说明页：如果你只希望明确要求时才生成网页版说明页，可在 Agent 全局规则（如 CLAUDE.md / AGENTS.md）写入 [archify explainer: on-demand]。
  • 关闭 PR 轻提示：装了 archify-pr 但只想手动调用时，在全局规则写入 [archify pr: on-demand] 即可。
  • 对外分享脱敏：Archify 默认在本地 .archify/ 目录生成自包含 HTML；向外部展示或贴入公开博客前，务必确认节点卡片与路径中未包含内网域名、真实表字段敏感信息或业务机密。

❓ 常见问题 FAQ

Q1：网上搜到的「Archify 在线生成网站」和付费套餐是官方提供的吗？

不是。原作者已在仓库首页和 #official-services 明确澄清：Archify 本体开源免费（Apache-2.0），官方入口只有 archify.si 与 github.com/tt-a1i/archify；任何第三方在线服务与收费套餐都不代表官方立场。

Q2：手里还没有代码仓库，只有脑子里的架构想法或一段 Mermaid，能用吗？

完全可以。直接说「用 Archify 画出：Browser -> API -> Redis 缓存 -> PostgreSQL 回源」，或贴入 Mermaid 草稿就能生成交互式 HTML；之后还可以继续在对话中说「增加限流网关」「突出回滚路径」，它会保留 Typed Source 做增量调整。

Q3：在公司私有项目里运行 Archify，会把源码上传到外部服务器吗？

不会。Archify 依托你当前使用的 AI Agent 在本地分析并产出独立的 HTML 文件，不经由任何第三方绘图 SaaS。若对默认的低频版本号检查也有顾虑，配置 ARCHIFY_UPDATE_CHECK_DISABLED=1 即可实现彻底零外联。

Q4：Windows 安装为什么一定要注意带 --copy？

Windows 默认非管理员权限下创建符号链接容易报错退出。官方推荐命令中加上 --copy 会直接复制完整 Skill 目录到 Agent 本地技能目录，Windows PowerShell 5.1 与 PowerShell 7+ 都能稳定安装。

Q5：archify 和 archify-pr 要一起装吗？

先装核心 archify 即可满足 90% 的画图、架构讲解与 Code Analysis 诊断需求。如果你的团队需要频繁在 GitHub PR / GitLab MR 中附带变更架构导览图，再按需加装 archify-pr 即可。
