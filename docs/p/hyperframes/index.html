⚖️ 架构对比：HyperFrames vs Remotion

原仓官方也坦诚受到 Remotion 启发，二者底层均使用 headless Chrome + FFmpeg 渲染，但在 Agent 协作成本与开源协议上有明显差异：

对比维度 HyperFrames Remotion
编排方式 纯 HTML + CSS + 可寻址动画适配器（GSAP / Lottie / Three.js / WAAPI） React / JSX 组件树
构建步骤 无构建步骤，单个 index.html 可直接打开预览 需要前端打包器（Webpack / Vite 等）
Agent 编写友好度 高（Agent 改局部 DOM 和时间轴属性不易破坏编译） 需维护 React 状态、依赖与类型编译
开源与商业许可 Apache-2.0（无渲染量限制或企业收费门槛） Source-available Remotion License（企业人数达阈值需商业授权）

❓ 常见问题 FAQ

Q1：不装任何桌面客户端，只用 Claude Code 就能做完视频吗？

可以。只要本机装好 Node.js 22+ 与 FFmpeg，安装 hyperframes 的 Core Skills 后即可纯命令行完成脚手架创建、HTML/GSAP 编写、preview 预览和本地 render 出片。

Q2：为什么普通 CSS/JS 定时动画不能直接拿去录视频，非要用 HyperFrames 适配器？

普通 requestAnimationFrame 或 setTimeout 依赖真实挂钟时间（wall-clock），截帧时机器一卡就会丢帧错位。HyperFrames 要求把 GSAP Timeline 等设为 paused: true 并注册到 window.__timelines，渲染器就能按任意毫秒精确寻址每一帧。

Q3：手里已有 Remotion 或 Lottie 项目想迁过来可行吗？

官方专门提供了按需技能 /remotion-to-hyperframes，支持把 Remotion、Motion Canvas、Lottie、Three.js 或 Canvas 工程迁移到 HyperFrames，并逐帧比对校验还原度。

Q4：可以把 Figma 设计稿直接变成产品介绍视频吗？

可以。按需安装 /figma 技能后，贴入 Figma 链接即可提取品牌 Token、组件与故事板画框并重构为可寻址动效。
