🧭 Step 0–6 工程化策划流与核心能力

与普通 AI “每张图都硬塞三行卖点、越改越不像原包装”不同，v3.0 把策划拆为 7 个带明确门禁的阶段：

0

任务路由与商品名确认

识别任务类型（主图 / 详情页 / Amazon A+ / 改稿 / 跨境本地化）。缺商品名时先请用户提供或明确授权“据图拟名”（拟名标明非官方原名），不把猜测写成已确认品牌。

1

核实卖点 → 生成《证据账本》

逐条核对卖点来源与适用范围，建立四级分类；任何销量、排名、检测、功效在没有资料支撑时一律标记“待确认”，绝不编造。

2

找准成交驱动力（1 主 + 至多 1 辅）

从视觉、痛点、参数、信任、情绪、价格组合促销 6 类中锁定主驱动力，提炼至多 3 条有依据的购买理由，按消费者决策顺序而非工厂参数表排序。

3

Campaign Style Lock + Reference Fidelity

统一锁定整套图的产品外观、包装 Logo、色彩、光影、字体与禁止漂移项，把包装变形、规格错误、人物多指等提前写进 Negative Prompt。

4

Storyboard 动态规划（KV1 先让人认出商品）

KV1 首图优先完成商品识别（商品名清晰时不超字数直接作主标题），后续每张图只解决一个决策问题；5 张只是默认起点，按信息密度动态增减。

5

逐图执行卡 + 文案规格检查

读取 references/output-contracts.md 输出画面、图内文案、排版、Prompt 与禁用项，并通过 scripts/count-copy.py 校验中英字数上限。

6

硬性阻断 + 80 分五维自审

交付前先扫描内部占位符（scripts/scan-final-copy.py），再按 5 个维度以必要条件为锚点自审，任一维度低于 80 分强制重写（最多 2 轮），随稿附《自审记录》。

⚖️ 文案规格默认阈值与合规安全边界

📏 防止画面文字过载的默认排版上限
  • 主图信息上限：1 个主标题（≤ 12 汉字 / ≤ 6 英文词）+ 至多 2 条副文案（每条 ≤ 18 汉字 / ≤ 10 英文词）+ 至多 1 个数字或证据标签。
  • 详情页（PDP）模块上限：1 个标题 + 至多 3 条要点（每条 ≤ 18 汉字 / ≤ 12 英文词）；超限优先删减或拆图，绝不缩字号硬塞。
🚫 能力边界与高风险类目提醒
  • 不做最终法律结论与自动上架：食品、保健品、医疗器械、儿童用品等高风险类目按保守口径筛查，实际投放仍以平台最新审核规则及专业法务为准；Skill 不会代操作店铺后台上架或投放。
  • 拒绝促销造假与跨境直译：无价目或活动依据时不编造“最低价 / 限时 / 原价”；跨境版本（Amazon / Shopify / TikTok Shop / Temu / Shopee / Lazada）必须按本地度量单位与表达习惯重写。

❓ 常见问题 FAQ

Q1：我自己没有专业拍照图，只有包装实拍或白底图能用吗？

可以。把包装实拍图、产品参数、资质截屏和参考风格图一并交给 Agent，它会在 Reference Fidelity 中锁定包装文字、Logo 和结构比例不得变形，并输出场景重建的生图 Prompt 与 Negative Prompt。

Q2：为什么说「一次性交付」也会附带《自审记录》？

SKILL.md 明确区分了「暂停确认」和「质量自审」：即使用户要求“不要中途提问，直接出全套”，Step 6 的五维 80 分自审依然会在同一轮内强制执行，确保未过线的初稿不会直接交付；但若未提供真实成图，成图验收项会诚实标为“待验收”。

Q3：这个 Skill 适合做纯短视频带货口播或直播间话术吗？

不适用。它的 frontmatter 明确排除了纯短视频/直播话术与店铺投放运营，专注在主图、商品图、详情页 PDP、Amazon Listing/A+、广告图文素材以及跨境视觉本地化。

Q4：怎么用仓库自带的测试脚本验证自己改过的 Prompt？

仓库提供了 test-prompts.json（含 31 类提示词期望）与 tools/evaluate-prompts.py，运行 python tools/verify-skill.py 与 python -m unittest discover -s tests -v 即可完成结构与文本断言回归测试。
