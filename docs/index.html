📖 什么是 Claude Code Skills？

可复用的指令模块，让 Claude Code 拥有特定领域的专业能力

⚡

即装即用

在 Claude Code 2.1+ 执行两条 /plugin 命令，或将 SKILL.md 目录复制到本地 skills 目录即可自动生效。

🎯

场景驱动

每个 Skill 聚焦一类高频工程或内容任务：代码审查、安全审计、英文 Skill 汉化、API 测试、视频制作。

🌏

中文优先

单独覆盖公众号、小红书、飞书、企业微信等国内生态，每条精选都说明中文场景收益与使用边界。

🔄

每周核验

只收录可核验的真实可复用资产，定期剔除失效与纯引流条目，并持续完善原创技能的跨平台兼容性。

📦 安装指南

覆盖 Claude Code 插件、macOS / Linux、Windows PowerShell 5.1+ 与按需单装，复制即可执行

⚡ Claude Code 插件一键安装推荐

适用于 Claude Code 2.1+，在交互窗口直接输入两条命令即可安装全部原创中文技能包：

/plugin marketplace add laolaoshiren/claude-code-skills-zh
/plugin install zh-skills@claude-code-skills-zh
🐧 macOS / Linux 一键安装

自动创建 ~/.claude/skills 并安装全部原创技能；GitHub 访问困难时切换至国内镜像：

git clone https://github.com/laolaoshiren/claude-code-skills-zh.git
mkdir -p ~/.claude/skills
cp -r claude-code-skills-zh/skills/* ~/.claude/skills/
🪟 Windows PowerShell 5.1+ 安装

原生兼容 Windows 10/11 内置 PowerShell 5.1 与 PowerShell 7+，无需 Git Bash：

git clone https://github.com/laolaoshiren/claude-code-skills-zh.git
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse -Force "claude-code-skills-zh\skills\*" "$HOME\.claude\skills\"
🎯 按需单技能安装 & ZIP 下载
⬇️ 下载 ZIP（GitHub） 🇨🇳 下载 ZIP（国内镜像）

只装单个技能避免上下文臃肿（解压 ZIP 后请将目录名替换为 claude-code-skills-zh-main）：

npx skills add laolaoshiren/claude-code-skills-zh --skill skill-translator
