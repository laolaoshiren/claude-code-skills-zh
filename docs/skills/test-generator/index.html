🎛️ 交互式测试框架与场景选择器

选择你当前的补测场景与项目语言栈，预览 test-generator 的测试层级决策、Mock 边界与复验规则（含与 api-tester 的自动分工提示）：

项目既有测试栈：
✅ 命中 test-generator · 快速确定性单元测试 沿用仓库现有 Vitest / Jest 命令与命名规范

纯函数、领域计算、格式化与解析器优先写无副作用单元测试

先读目标函数签名、类型定义和真实调用方，只针对契约中实际可达的输入组合设计参数化断言，验证可观察输出，不把内部私有步骤写死成脆弱断言。

取证与断言原则 区分「代码当前行为」与「产品期望行为」；两者冲突时先列证据与待确认假设，不用测试固化猜测。
Mock 与资源隔离 纯逻辑无需 Mock；如涉及当前时间或随机数，仅在系统边界注入可控时钟或种子。
跨平台与复验护栏 使用 path API、系统临时目录与显式 UTF-8 编码；只运行目标测试，基线已有失败与本轮新增失败分开记录。
优先运行 package.json 中已有测试脚本（例如 npm test -- path/to/target.test.ts），不擅自安装新测试框架或修改 lockfile。

🧭 5 步契约驱动补测流程

1

读取真实契约与现有测试基线

先检查目标函数的类型定义、公开文档、调用方、错误处理路径，以及仓库既有的测试文件、fixture、依赖清单与测试命令，并核对当前 git status 避免覆盖用户改动。

2

按模块性质选择测试层级

纯逻辑优先写快速确定的单元测试；涉及组件协作时使用临时目录、测试库或受控服务写模块集成测试；修 Bug 时先写能稳定复现问题的最小回归用例。

3

按可达路径设计参数化用例

每个用例写明对应契约或分支、输入安排、可观察结果和清理逻辑；只覆盖真实可达的正常、边界与失败路径，不机械堆砌空值、超时或无关数据库异常。

4

最小范围实现与跨平台安全

只改目标测试文件和必要 fixture，沿用仓库原有命名（不强行使用中文函数名）；跨 Windows/Linux 统一使用路径 API、系统临时目录和显式编码，不硬编码 /tmp、分隔符或时区。

5

先检查脚本副作用，再运行与复验

运行前确认测试脚本不会下载依赖或访问外部服务；确认失败与通过状态、区分基线失败与新增失败，并检查 git diff 无残留快照、缓存或覆盖率产物。

🛡️ 分工边界与安全护栏

场景类型 优先使用技能 核心区别与执行边界
函数 / 类 / 领域逻辑 / 数据层 test-generator 依据代码签名、调用方与模块契约写单元测试或非 HTTP 集成测试，隔离时间/文件/网络边界。
HTTP / REST / GraphQL / gRPC 路由 api-tester 依据 OpenAPI、路由与响应拦截器测试接口状态码与业务信封，受三档环境授权门禁保护。
代码规范与 Lint 规则报错 eslint-fix 锁定项目本地 ESLint 版本，先只读基线再限定范围修复并复验，不属于功能单元测试范畴。
⚠️ 五条硬性授权与数据安全红线
  • 不擅自改环境：未经明确授权，不安装或升级测试框架，不修改 lockfile、全局测试配置、CI 或生产代码。
  • 不碰真实生产资源：未经明确授权，不访问真实网络、生产数据库、云服务或带真实凭据的环境。
  • 测试数据零隐私：绝不在 fixture 或断言中写入真实个人信息、Token、Cookie、密码或客户数据。
  • 用例隔离可重复：不依赖测试执行顺序，结束后清理自建临时文件与状态。
  • 如实汇报验证态：未能实际跑通测试命令时，只能报告「已生成、未验证」，绝不虚报通过。

❓ 常见问题 FAQ

test-generator 和 api-tester 在测试场景上怎么分工？

test-generator 聚焦函数、类、领域逻辑与非 HTTP 服务层模块测试；如果要测 HTTP/REST/GraphQL/gRPC 路由、OpenAPI 契约或接口鉴权与业务错误码信封，应使用 api-tester。

仓库还没装测试框架，它会自动执行 npm install 或 pip install 吗？

不会。未经明确授权，它不安装或升级测试框架，也不修改 lockfile、全局测试配置或 CI。缺失运行环境时会先列出证据并请用户授权。

发现代码实现疑似有 Bug，它会顺手改业务代码让测试变绿吗？

不会。技能严格区分「代码当前行为」与「产品期望行为」：若发现产品缺陷，会单独报告或在用户明确要求修复时先写最小复现回归用例，再验证修复。

生成的测试文件为什么不会在 Windows 上翻车？

规则明确禁止硬编码路径分隔符、/tmp、换行符、大小写、时区和 locale 行为，统一要求使用语言原生的路径 API、系统临时目录和显式编码。
