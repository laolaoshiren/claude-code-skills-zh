🎛️ 交互式判别：你的测试环境属于哪一档门禁？

点击当前测试环境类型，查看 api-tester 实际会执行哪些安全检查（避免一刀切阻断离线单测，也防止本地服务暗连共享库）：

档位 1：核实隔离后可直接运行，无需机械追问

纯进程内 Mock / 内存隔离库模式

快速验证不会外连真实数据库、消息队列或付费外部 API 后，直接复用仓库锁定测试命令运行回归，保证日常开发流丝滑不被打断。

  • 核实测试客户端走进程内注入，不发真实外网请求
  • 使用项目锁定的 test script，严禁裸 npx 临时拉最新版
  • 凭据仅通过测试变量/环境变量名引用，绝不读真实 .env 明文

📋 契约取证链与 Spec Drift 三级处置

无 OpenAPI 时的国内项目取证链

  • 1. 路由注册表、鉴权/限流/参数校验中间件与 DTO/Validator；
  • 2. Controller / Handler 的入参解构、分支条件与返回语句；
  • 3. 全局响应拦截器与业务错误码枚举（精准识别 HTTP 200 + { code, msg, data } 信封）；
  • 4. 现有前端/SDK 调用方、存量测试及数据库约束。

契约缺失或冲突（Spec Drift）三级处置

  • 规范与实现一致：生成精确状态码、业务码与字段结构正式断言；
  • 无文档但代码可达：生成现状回归用例，并显式标注「代码反推，待业务确认」；
  • 文档与代码冲突：严禁擅改代码凑绿灯！标 skip/todo 并在报告单列「契约偏差与风险发现」。

⚡ 安装方式与 Windows PowerShell 调试避坑

方式 1：Claude Code 2.1+ 一键安装 
/plugin marketplace add laolaoshiren/claude-code-skills-zh

New-Item -ItemType Directory -Force "$HOME\.claude\skills\api-tester" | Out-Null
Copy-Item -Recurse -Force ".\claude-code-skills-zh\skills\api-tester\*" "$HOME\.claude\skills\api-tester\"
方式 4：macOS / Linux 
git clone https://github.com/laolaoshiren/claude-code-skills-zh.git
mkdir -p ~/.claude/skills/api-tester
cp -r claude-code-skills-zh/skills/api-tester/* ~/.claude/skills/api-tester/
Windows PowerShell 调试避坑：PowerShell 中 curl 默认是 Invoke-WebRequest 别名，直接粘贴带单引号 JSON 的 Unix curl 命令必报错；手工复现请显式使用 curl.exe 或直接跑项目测试框架，且严禁在命令中展开 .env 明文 Token。

❓ 常见问题 FAQ

我只让它生成接口测试代码，它会自动发请求打接口吗？

不会。技能明确区分「生成测试」与「执行测试」——只要求生成测试时仅产出代码，且输出状态会诚实标为 仅生成未执行。

什么时候该用 api-tester，什么时候用 test-generator？

HTTP / REST / GraphQL / gRPC 路由与网络契约验证用 api-tester；纯函数、工具类、领域模型或模块内部单元测试用 test-generator，压测与火焰图定位交 perf-profiler。
